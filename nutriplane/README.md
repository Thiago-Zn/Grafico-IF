# NutriPlane v0.2 Skeleton

Este diretório contém a base inicial do Web App NutriPlane usando React + Vite.
O objetivo é fornecer uma estrutura mínima para navegação entre telas e futuro
crescimento do projeto.

## Scripts

```bash
npm install
npm run dev
```

## Estrutura de pastas

- `src/routes` – páginas principais (Home, Planejamento, Compras, Resumo, Importar)
- `src/components` – componentes reutilizáveis
- `src/data` – base de alimentos simplificada
- `src/utils` – funções auxiliares
- `styles/tailwind.config.js` – configuração do TailwindCSS

As funcionalidades estão em forma de placeholders para facilitar futuras
implementações.
